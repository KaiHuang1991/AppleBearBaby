给后台逐条对照改 **Name / Model number / Description**。对象是海外 OEM、进口商、批发采购，不是宝妈零售。

数据来自 2026-09-15 线上 `https://applebearbaby.net/api/product/list?all=true`。

---

## 怎么改

1. 打开后台商品列表，点进每一款（路径：`/admin/single/{商品ID}`）。
2. 把本文的 **新标题** 贴到 **Name**。
3. 把 **建议型号** 贴到 **Model number**（已有型号的只去掉中文后缀）。
4. 描述框全选删除，粘贴对应的 **新描述**（可直接贴 HTML）。
5. 保存。不要动 **Slug**。
6. 打开商品页 → 右键「查看网页源代码」，确认 `<title>` 和 `meta description` 已变成新文案。
7. 在 [Search Console](https://search.google.com/search-console) 对该 URL 请求编入索引。

建议先改带中文标题和礼盒的款（第 1、2、16–19 款），再改单瓶。

---

## 必须遵守

| 做 | 不要做 |
|---|---|
| 标题：`型号 + 容量 + 口径/材质 + OEM/Wholesale` | 写 cute / fuss-free / busy parents / baby shower gift |
| 型号栏只留工厂编码（如 `8005C`、`AB-117`） | 型号栏写「大小肚瓶5件套」 |
| 描述写规格、装箱、印刷、MOQ、交期 | 写给小手抓、新生儿礼物、公主套装 |
| **Slug 保持原样** | 改名后点「按标题重新生成 slug」——旧 Google URL 会失效 |
| 中文只留在你们内部备注 | 前台标题出现「大小元组合」 |

MOQ、pcs/ctn、交期下面用了工厂常见值。和你们报价单不一致时，**以工厂为准改数字**，句式不用改。

每款描述末尾都有同一段询盘说明，保持即可。
